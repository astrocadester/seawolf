# Mark Spaeth's Sea Wolf reconstruction

These two source files are preserved from Mark Spaeth's public `mcspaeth/seawolf_z80` repository:

https://github.com/mcspaeth/seawolf_z80

- `seawolf.asm` — annotated, restructured Sea Wolf assembly source, including experimental modifications and configuration options.
- `seawolf_dz80.asm` — address-oriented disassembly with hexadecimal machine bytes and comments.

Copied as reference material on 2026-10-30. **Neither file is the authoritative original-ROM reconstruction for this repository.** Our `src/seawolf.asm` is based on `roms/original/seawolf.zip`; compare modifications against the original ROMs rather than assuming the reference assembles byte-for-byte to the 1976 game.

Original authorship and commentary remain with the upstream source. Consult the upstream repository for any licensing or use terms; this directory does not assert a new license over these reference files.
